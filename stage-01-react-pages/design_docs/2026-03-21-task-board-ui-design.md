# Stage 01 任务面板 UI 设计方案

## 概述

本文档定义了经批准的第 1 阶段（Stage 1）教学向任务面板页面的 Web UI 设计。该页面特意保持简洁，采用清爽的视觉风格，并确保布局稳定。这样在后续的 React 开发需求中，可以在不重构页面的情况下，引入 Props、State、事件处理、条件渲染及列表更新等知识点。

Pencil 原型稿：
- 活跃设计文件：`pencil-welcome-desktop.pen`
- 屏幕框架 ID：`3ew7D`

## 视觉方向

- **风格**：教学导向的极简主义
- **主题**：浅色模式（Light）
- **密度**：宽松、易读、低视觉噪音
- **目标**：让学习者在处理复杂交互之前，先理解页面区域划分和组件边界。

## 页面结构

页面为一个居中的单列工作区，由上至下分为四个固定区域：

1. `Header` (页眉)
2. `SummaryCards` (统计卡片)
3. `FilterBar` (筛选栏)
4. `TaskList` (任务列表)

此顺序建立了清晰的信息流：
- 首先看到页面身份
- 接着看到任务总体概况
- 然后看到筛选控制控件
- 最后查看具体的任务条目

## 区域详情

### 1. Header (页眉)

**用途**：
- 确立页面身份
- 展示最基础的页面结构
- 提供标题、简短描述和当前日期

**内容**：
- 上标（Eyebrow）：`Stage 01 · React Pages`
- 标题：`今日任务面板`
- 描述：`用清晰的页面结构练习组件拆分、Props 传值与后续状态管理。`
- 日期徽标：`2026-03-21`

**视觉处理**：
- 白色卡片底色
- 细边框
- 适中的圆角
- 标题使用 `JetBrains Mono` 字体
- 辅助文字使用 `Geist` 字体

### 2. SummaryCards (统计卡片)

**用途**：
- 提供简单的概览区块
- 为 Props 传递和派生变量（Derived Values）提供自然的练习案例

**布局**：
- 单行横向排列
- 三张等宽卡片

**卡片内容**：
- `总任务数` → `4`
- `已完成` → `2`
- `未完成` → `2`

**视觉处理**：
- 沿用 Header 的卡片设计语言
- 总数值使用中性前景色
- 已完成数值使用成功色（Success）前景色
- 未完成数值使用警告色（Warning）前景色

### 3. FilterBar (筛选栏)

**用途**：
- 为后续的状态和事件处理预留位置
- 在接入逻辑前，先从视觉上引入筛选功能

**内容**：
- 辅助说明：`静态展示筛选按钮，REQ-02 再接入 state 与条件渲染。`
- 筛选按钮：
  - `全部`
  - `进行中`
  - `已完成`

**视觉处理**：
- 整个工具栏位于独立的白色面板内
- 按钮样式采用胶囊组（Pill Group）设计
- 在静态设计中，`全部` 为默认激活状态

### 4. TaskList (任务列表)

**用途**：
- 提供核心内容区域
- 为列表渲染、状态显示及后续的任务变更创建直接路径

**区块标题**：
- 标题：`任务列表`
- 元信息文字：`4 个静态示例任务`

**任务项结构**：
- 标题
- 简短描述
- 状态标签

**静态示例任务**：
- `完成 Stage 1 项目初始化` → `已完成`
- `拆分 Header 与 SummaryCards 组件` → `进行中`
- `准备静态任务数据结构` → `已完成`
- `为 REQ-03 预留新增任务入口` → `进行中`

**视觉处理**：
- TaskList 采用白色面板
- 每个任务项为颜色更浅的内部行卡片
- 状态标签使用设计系统中的语义化变体颜色

## React 组件映射

该设计有意与直观的 React 组件拆分保持一致：

- `Page` (页面总控)
- `Header` (页眉)
- `SummaryCards` (统计卡片)
- `FilterBar` (筛选栏)
- `TaskList` (任务列表)
- 可选组件：`TaskCard` (任务卡片)

**第 1 阶段推荐静态数据字段**：
- `title` (标题)
- `description` (描述)
- `status` (状态)

**推荐筛选值**：
- `all` (全部)
- `in-progress` (进行中)
- `completed` (已完成)

## 需求演进

### REQ-01
**重点**：
- 静态渲染页面
- 将页面拆分为展示性组件（Presentational Components）

### REQ-02
**重点**：
- 将 `FilterBar` 连接到本地状态（Local State）
- 根据激活的筛选器条件渲染任务
- 从任务数据或 Props 中计算统计值

### REQ-03
**重点**：
- 添加任务创建功能
- 添加完成状态切换功能
- 保持 `SummaryCards` 和 `TaskList` 数据同步

## 设计约束

- 无侧边栏
- 无多列仪表盘布局
- 无图表
- 无远程数据请求
- 除三个筛选选项外，无复杂控件
- 无任何会分散 React 基础学习注意力的视觉复杂性
