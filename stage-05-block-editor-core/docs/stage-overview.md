# Stage 5 Overview: Block Editor Core

## Objective
Build the core of a Notion-style block editor without expanding into the full product scope of Notion itself.

## Scope
- block-based document model
- paragraph, heading, todo, and code blocks
- create, delete, split, merge, and move block operations
- slash menu behavior
- persistence and replay

## Out of Scope
- real-time collaboration
- page trees and workspace management
- databases and views
- permissions

## Requirement Sequence
### REQ-01
Define the block model and render a minimal block document.

### REQ-02
Implement core block operations and focus transitions.

### REQ-03
Add a simple slash menu and persistence flow.
