# Tiptap 编辑器学习程序实施计划

> **给 AI 的指令：** 需要子能力：使用 `executing-plans` 来逐项执行此任务计划。

**目标：** 为一个分为五个阶段的 React 到 Tiptap 课程创建学习计划工作区、文档骨架以及各阶段的入口点。

**架构：** 在此步骤中，代码仓库保持“文档优先”。根目录文档定义路线图和流程，而每个阶段包含自己的应用（app）工作区和需求文档。在搭建任何应用程序代码之前，首先准备好第一阶段（Stage 1），以便进行深入的规划讨论。

**技术栈：** Markdown 文档、文件系统结构、Git 仓库
