# Stage 01 REQ-02 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为任务板加入筛选交互和动态摘要，让页面从静态展示推进为数据驱动视图。

**Architecture:** `App.tsx` 作为唯一状态持有者，保存 `filter` 并派生统计值与筛选后列表。`FilterBar`、`SummaryCards` 和 `TaskList` 都保持展示型组件，通过 props 接收状态、回调或派生值。

**Tech Stack:** React, TypeScript, Vite, 原生 CSS
