# Stage 01 REQ-03 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为任务板加入新增任务、状态切换与 `localStorage` 持久化，让阶段 1 收口为一个真正可用的小型应用。

**Architecture:** `App.tsx` 统一持有 `tasks + filter` 两个状态源。`TaskForm` 只收集输入并上交，`TaskCard` 只发出切换事件，`SummaryCards` 和 `TaskList` 继续接收派生值。`localStorage` 围绕 `tasks` 在 `App` 层接入。

**Tech Stack:** React, TypeScript, Vite, 原生 CSS, localStorage
