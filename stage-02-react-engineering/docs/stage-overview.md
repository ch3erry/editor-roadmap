# 第二阶段概览：React 工程化实战

## 教学目标
从基础的页面搭建转向维护一个具备清晰结构、可复用模式及基础工程化规范的小型前端应用。

## 涵盖范围
* **路由管理** (Routing)
* **共享布局** (Shared Layouts)
* **异步数据模式**（结合本地 Mock 数据）
* **交互状态处理**：加载中 (Loading)、空状态 (Empty) 及错误处理 (Error)
* **代码规范**：Lint 检查与格式化 (Linting & Formatting)
* **进阶重构**：自定义 Hook 封装与组件边界清理

## 需求开发序列

### REQ-01：工程基座搭建
完成基础工程化环境配置，统一项目脚本（Scripts）与代码格式化规范。

### REQ-02：动态架构实现
引入路由系统与通用布局，并实现异步 UI 状态切换。

### REQ-03：逻辑抽离与优化
重构共享逻辑，精简并优化项目整体目录结构。

---

**💡 这里的“小贴士”：**
在 Tiptap 的教学语境下，**REQ-03** 特别重要。因为编辑器往往涉及大量的事件监听和状态同步，在这一步引入“自定义 Hook”能为后续第三阶段接入 Tiptap 核心 API 打下极好的代码基础。
